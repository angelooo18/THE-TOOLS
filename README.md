# TOOLS — the MiMo-Tool family

Workspaces for [pi](https://github.com/earendil-works/pi) tuned for Xiaomi
**MiMo V2.6** models. Two tools, one philosophy: the orchestrator plans and
verifies, disposable subagent trees implement, files are the memory.

| Tool | What it is |
|---|---|
| **[MiMo-Tool-Code](MiMo-Tool-Code/)** | Hardened **boss → leads → leaves** coding workspace. Delegate-guard physically stops the orchestrator from writing code; fork inheritance hands full planning context to implementers; verify gates and self-contained briefs kill the "phone effect"; optional observational memory keeps the boss's context crisp indefinitely. |
| **[MiMo-Tool-Learn](MiMo-Tool-Learn/)** | **learn-studio** — learn any topic with a tutor that teaches for *understanding* (not memorization), renders LaTeX + Mermaid into an Obsidian vault, quizzes you, and remembers where you left off across sessions. |

## Requirements (both)

- [pi](https://github.com/earendil-works/pi) ≥ 0.99.2 — `pi update self`
- tmux (subagent panes require it)
- A Xiaomi MiMo API key
- Packages: `pi install git:github.com/amosblomqvist/pi-interactive-subagents`
  and `pi install git:github.com/amosblomqvist/pi-observational-memory`

Each tool ships its own README with full install + usage, an MIT license, and
credits. Built with pi's extension ecosystem by
[Amos Blomqvist](https://github.com/amosblomqvist) — subagent + memory engines,
and the original `learn` system.
